The edit form

The edit form for one record, after a save that failed on one field. The fields keep the places they have on the details page. The markup is what the tag helpers emit, trimmed to the attributes the brand reads; a required field gets its asterisk from that markup, and the invalid email shows the classes ASP.NET Core adds. The action bar stays at the bottom of the window while the form scrolls.

Create dialog

A new record starts in a dialog over the list, with only the fields it needs to exist; the rest are on its edit form. The button opens the dialog with commandfor and command="show-modal", so there is no script. Without HTMX the New contact link opens a create page with the same form instead.

Relation picker

Change, or Choose, opens a dialog built from the list components: a filter box and a grid with a radio in each row. It lists active records only; an archived company cannot be chosen.
