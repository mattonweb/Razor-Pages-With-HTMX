Feedback

Telling the user what happened, what is happening, or what is about to. An action that can be undone runs at once and says so in a toast with Undo; only an action that cannot be undone asks first, in a confirm dialog; a state that lasts is a banner on the page. The styles are in assets/css/feedback.css.

Alert

A banner between the page header and the content, about a state that lasts. An icon, the message, then at most one or two actions. The text keeps the page's color; the tone colors the icon, the fill and the line. A failure that needs attention now is role="alert"; the rest are role="status".

Toast

A short message about an action that just ran, with Undo when the action can be undone. Toasts appear in one <div class="toasts" role="status" aria-live="polite"> that sits in the layout, empty, until the server adds one. A toast leaves by itself after 8 seconds, waiting while the pointer or keyboard is on it. Below, three held still; the button sends a real one to the bottom of the window.

Dialog

A native modal <dialog class="dialog"> with .dialog-header, .dialog-body and .dialog-footer, directly or inside one <form>. Buttons open and close it with commandfor and command, so it needs no script; Escape closes it and the page behind is inert. The footer ends with the one primary action.

Confirm dialog

Only for an action that cannot be undone. A .dialog.sm: the title asks the question and names the record, a .dialog-icon in the dialog's tone leads the message, the safe choice comes first with autofocus, and the destructive .btn.danger comes last. When the action is not allowed at all, the dialog says why and what to do instead, and offers no way to force it.

Busy bar

A 2px line under a card's toolbar that runs while a request from the card is in flight, while the rows dim; the toolbar stays usable. HTMX's .htmx-request shows it, and so does aria-busy="true" without HTMX. A button that sent a request shows its own spinner instead; see Buttons on the Foundations page.

Bulk bar

What can be done to the rows checked in a grid's selection column. Every row's checkbox names one empty <form id="bulk-form" method="post"> in the card with form="bulk-form". The bar follows the grid, appears with the first checked row and counts them, in CSS alone; Clear is a reset button for that form, and each action is a submit button with its own formaction. An action that cannot be undone is .danger and comes last.
