Foundations

Color, type, space, shape, icons and buttons. Every value is a token in assets/css/tokens.css; element defaults, icons and buttons are in assets/css/base.css.

Color

Blue marks anything you can click. Violet is the brand: the logo, the user avatar and version badges, never a button. The values printed are for the current mode; the moon button in the header switches it.

Icons

Line icons on a 24px grid, drawn for this repository and kept in one sprite, assets/icons.svg. They take the color of the text around them. An icon next to a label is aria-hidden; an icon alone sits in a button that has an aria-label.

Buttons

One primary button per view. Danger is only for an action that cannot be undone; an action that can be undone, such as archiving, is a secondary button.
