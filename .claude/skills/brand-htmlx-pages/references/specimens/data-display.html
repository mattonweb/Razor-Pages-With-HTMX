Data display

Showing records and their values. The styles are in assets/css/data-display.css.

Grid

A table of records in a .grid-wrap, which scrolls sideways when the card is too narrow. The first column is the title cell: a link to the record, then a muted second line in .sub. A sortable header is a link; the sorted one carries aria-sort and shows its arrow, and the others show theirs on hover or focus. Numbers are right-aligned in .num. An archived row among active ones has class="archived" and a neutral chip. The last column holds the row's menu button; in a page each row's menu has an id built from its record's id, where here all the rows share one.

Selection column

A .select cell first in each row, with a checkbox (or, in a picker, a radio) whose label is the row's title, so a click on the name selects the row too. A checked row is highlighted. The header's box selects every row on the page; it is one of the two pieces of the brand that need script. The bulk bar that acts on the selection is on the Feedback page.

Timeline

A record's versions, newest first, in an <ol class="timeline" reversed>. Each entry is a <details> whose summary holds a chevron, the version badge, what happened and who did it when; opening it shows the diff and the entry's actions. The current entry is li.current and has no actions.

Diff

Field, Before, After, as <del> and <ins>, for only the fields that changed. The column headers carry the meaning, so the colors only reinforce it; a missing value reads "Not set". In a .diff-wrap it scrolls sideways below 440px, as a grid does.

Side panel

A quick look at one record without leaving the page: a native popover, <aside class="panel" popover>, that slides in from the right with the record's fields, and Open full record and the one primary action in its footer. It is not modal: the page beside it stays usable, the row it shows carries aria-selected="true", and Escape, the close button or a click outside closes it. Click Pat Example below. The name is still a link to the record's page, so without script it opens that page.
